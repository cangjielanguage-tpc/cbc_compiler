Feature 3: minimization

Благодаря фиче 1 выяснилось, что 19 тестов падают одинаково по ассерту в typeinfo_factory.cpp. Это самый большой по размеру кластер среди развалов, начать отладку эффективнее с него. Берем представителя (`compiler/CHIR/AST2CHIR/BaseUseCase/extend/extend_interface4.cj`), запускаем минификатор (line-based ddmin, 60sec time limit). Спустя минуту у нас уменьшенный (559 -> 189 bytes) пример, который падает точно так же:

```
interface A {
    func foo(): Int64 {
        return 0
    }
}
interface B {
    func foo(): Int64
}
class S {}
extend S <: A & B {}
main(): Int64 {
    let b: B = S()
    return b.foo()
}
```

Результат #1: создается отдельная папка с репродьюсером и всеми подходящими скриптами для отладки (chir.txt, cbc.asm.txt, reproduce.sh etc). Удобно людям.
